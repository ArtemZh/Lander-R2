# Lander R2 — interactive demo page

Двомовна (UK/EN) демо-сторінка дротяної скульптури-посадкового модуля з живим екраном погоди:
процедурна 3D-модель (Three.js), покрокова збірка, список деталей, схема пінів, емулятор екрана
з реальною погодою (Open-Meteo) і три версії продукту — TFT (оригінал), OLED-тач, e-ink.

Bilingual (UK/EN) demo page for a wire lander sculpture with a live weather screen: procedural
Three.js model, step-by-step assembly, parts list, pinout, screen emulator with real weather
(Open-Meteo) and three product variants — TFT (original), OLED touch, e-ink.

**Live:** https://artemzh.github.io/Lander-R2/

Static site, no build step: `python3 -m http.server` and open `index.html`.
