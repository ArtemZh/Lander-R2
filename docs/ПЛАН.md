# Lander R2 — інтерактивна сторінка: план

Репозиторій: https://github.com/ArtemZh/Lander-R2 (порожній, заповнюємо з нуля).
Джерело: збережена стаття Мохіта Бхойта `Lander R2 _ Mohit Bhoite.html` + 40 картинок.

## 1. Мета

Одна статична **публічна** сторінка на GitHub Pages (репо public) з трьома розділами-версіями одного продукту:

| Версія | Екран | Контролер | Ідея |
|---|---|---|---|
| **R2 Original** | TFT 1.9″ 170×320, ST7789 | Particle Photon 2 | Точна копія оригіналу, повний опис збірки |
| **R2 Touch** | AMOLED / OLED ~1.9–2.4″ з ємнісним тачем | ESP32-S3 (PSRAM 8 MB) | Керування пальцем: свайп сторінок, налаштування міст, будильник |
| **R2 Ink** | E-ink 2.13″ (250×122) або 2.9″ (296×128) | ESP32-C6 або nRF52840 | Тижні роботи від батареї, deep sleep, оновлення раз на N хвилин |

Кожна версія: 3D-модель, яка збирається по частинах + опис + список деталей + схема підключення.

## 2. Структура сторінки

```
/                       Hero: 3D модель Original, що повільно обертається, заголовок, 3 кнопки-перемикачі версій
├── #build              Покрокова збірка (scroll-driven): деталі прилітають на місце
├── #parts              Список деталей (інтерактивний: клік на рядок → підсвічує деталь у 3D)
├── #wiring             Схема пінів (таблиця з оригіналу) + підсвічування дроту в 3D при наведенні
├── #screen             Емуляція інтерфейсу екрана прямо в браузері (canvas 170×320, живий час/погода)
├── #firmware           Опис прошивки, вебхуків, посилання на код
├── #versions           Порівняння трьох версій (таблиця + перемикач 3D-моделі)
└── #gallery            Фото з оригіналу
```

Перемикач версії вгорі змінює: 3D-модель, список деталей, схему пінів, емулятор екрана.

## 3. 3D-модель

**Інструмент:** Blender (є MCP) → експорт `.glb` → Three.js на сторінці.

Деталі як окремі об'єкти (щоб анімувати збірку і підсвічувати):

1. Зовнішній каркас-«шкаралупа» (латунь 20 AWG, прямокутна коробка)
2. Внутрішнє шасі (тримає плату+екран)
3. Плата Photon 2 (Feather form factor, 51×23 мм)
4. Дисплей TFT 1.9″ (з обрізаними вушками)
5. PDM-мікрофон (маленька синя плата збоку)
6. Бузер (чорний циліндр з іншого боку)
7. Рюкзак-клітка з батареєю 14250 (½ AAA)
8. Слайд-вимикач
9. Антена з червоним LED на вершині
10. 4 ноги (зігнутий дріт, трикутні розкоси)
11. 4 посадкові диски Ø14 мм

Порядок збірки в анімації = порядок у статті: шасі → плата+екран → шкаралупа → рюкзак/батарея → ноги → диски (диски останні, як у оригіналі).

Матеріали: латунь (metallic, roughness 0.3), чорний PCB/зелений PCB, скло екрана з emissive-текстурою (скриншот інтерфейсу).

Для Touch і Ink — та сама база, замінені: плата (ESP32-S3 / C6 у Feather-форматі, напр. Adafruit Feather ESP32-S3 / Xiao), екран (товщий OLED / тонкий e-ink з шлейфом), для Ink — більша батарея.

## 4. Емулятор екрана (#screen)

- Canvas 170×320 з фоновим BMP-макетом (оригінальний `background04.bmp` є в папці).
- Живі дані: час користувача, погода з Open-Meteo (без ключа), схід/захід, фаза місяця (порахувати формулою), вологість, вітер — ті ж віджети, що на фото.
- Трюк «тінь 88:88» відтворити 1:1.
- Для Touch: тач-жести на canvas (свайп між екранами).
- Для Ink: ч/б рендер, імітація часткового оновлення (мигання).

## 5. Технології

- Один `index.html` + `css/` + `js/` — без бандлера, щоб просто працювало на GitHub Pages.
- Three.js (CDN), GLTFLoader, OrbitControls; анімація збірки — прив'язана до scroll (IntersectionObserver / scroll progress).
- Дві мови: **українська + англійська**, перемикач у шапці, тексти в `i18n/{uk,en}.json`.
- Мобільна версія: 3D зменшений, збірка — кнопками «далі/назад» замість скролу.

## 7. Етапи

1. **Blender:** модель Original по частинах (з фото + розміри Feather 51×23, екран 1.9″ 170×320 ≈ 24×45 мм активна зона) → `.glb`.
2. **Сторінка-каркас:** hero з 3D, розділи, перемикач версій (поки всі три показують Original).
3. **Збірка по скролу** + підсвічування деталей зі списку/пінів.
4. **Емулятор екрана** з живими даними.
5. **Touch і Ink:** моделі-варіанти, BOM, пін-схеми, відмінності прошивки.
6. Фото-галерея, README, GitHub Pages.

## 8. Відкриті питання

- Розмір OLED для Touch: 1.9″ (як оригінал) чи більший 2.4″ (каркас треба збільшувати)?
- E-ink: 2.13″ поміщається в оригінальний каркас, 2.9″ — ні. Який?
- Рендерити екран у 3D-моделі живим (canvas-текстура) чи статичною картинкою?
- Реальну прошивку для Touch/Ink писати в цьому репо чи лише описувати?
