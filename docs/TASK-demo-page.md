## 3D-модель — процедурно в Three.js (`js/lander-model.js`), без .glb
Одиниця — мм. Функція `buildLander(version)` повертає `THREE.Group` з дочірніми групами `name` = id кроку.
Референс пропорцій: плата Feather 51×23×1.6; дисплей 1.9″ ≈ 50×30 мм плата, активна зона 24×45 (портрет); шкаралупа ≈ 30×32×60 (Ш×Г×В); ноги розходяться до квадрата ~90×90, висота корпусу над столом ~35; диски Ø14, товщина 0.5; батарея 14250 Ø14×25; антена висота 60 над верхом, LED червоний сферa r=1 з PointLight; бузер Ø12×6 чорний циліндр з боку; мікрофон плата 12×15 синя.
Дріт: `TubeGeometry` по `CatmullRomCurve3`/`LineCurve3`, r=0.4 (20 AWG ≈ 0.8 мм), матеріал `MeshStandardMaterial` metalness 0.9 roughness 0.3 color #c9a227. Ноги: кожна — 2 стійки + трикутні розкоси (як на фото: подвійна паралельна стійка з поперечками). Екран — `PlaneGeometry` з `CanvasTexture` (той самий канвас емулятора; для original/touch — кольоровий, для ink — ч/б) — можна просто оновлювати `texture.needsUpdate` раз на секунду. Плата — темно-синя (Photon 2) / чорна (ESP32) коробка з USB-C блоком і кількома «чіпами».
Освітлення: hemisphere + 2 directional + point на LED. Фон прозорий, під моделлю — м'яка кругла тінь (ShadowMaterial або градієнтна площина).
Анімація збірки: кожна група має `userData.home` (позиція) і `userData.from` (зміщення для «прильоту»); `setStep(n)` виставляє target-видимість/позицію, у `render` — lerp.

## Таблиця пінів (original)
Display: GND→GND, VCC→3V3, SCK→SCK, MOSI→MOSI, RST→D4, DC→D5, TCS→D3, SDCS→D6, Lite/MISO — не підключати.
PDM Mic: VIN→3V3, GND→GND, DATA→A1, CLK→A0, SEL — не підключати.
Buzzer: +→D1, −→GND. Battery: +→Li+ (через вимикач), −→GND. LEDs через 220 Ω: red→RX, green→D0.
